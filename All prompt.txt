11. UX CONSTITUTION
============================================================

Follow these rules:

1. Quick Path is default.
2. Exploration Path is always optional.
3. Never force visitors to answer questions.
4. Never force visitors to watch an intro.
5. Never lock important information behind animation.
6. Important information must remain discoverable without understanding the interactive system.
7. Every interaction must have a reason.
8. Animation must help understanding.
9. Visitors can always return to Quick Path.
10. Contact requires minimal steps.
11. AI is optional.
12. Custom cursor is never required.
13. WebGL is never required.
14. Mobile is intentionally designed.
15. If a feature makes the site slower, confusing, or tiring, simplify or remove it.

Additional UX rules:

3-SECOND RULE:
The visitor should understand the basic identity and purpose quickly.

NO DEAD END:
Every major interactive state must provide a clear next action or exit.

GRACEFUL EXIT:
Visitors can leave an interactive experience at any time.

MINI-GAME:
Bonus only.
Never auto-open.
Never block content.

BORING IS SOMETIMES CORRECT:
If a simple solution communicates better, use it.

Overall philosophy:

SIMPLE TO ENTER.
FAST TO UNDERSTAND.
OPTIONAL TO EXPLORE.
DELIGHTFUL TO DISCOVER.
EASY TO CONTACT.
